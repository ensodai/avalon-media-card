# Windows x64 libmpv Binaries

В этой директории находятся нативные динамические библиотеки `libmpv` для Windows (64-bit).
При сборке приложения JNA автоматически распаковывает и загружает эти DLL без необходимости ручной установки со стороны пользователя.

## 🚀 АВТОМАТИЗАЦИЯ СКАЧИВАНИЯ (Linux / macOS)
Если вы собираете проект на Linux или macOS, **вам ничего не нужно делать вручную!** 
Специальная задача Gradle `downloadMpv` автоматически скачает последнюю версию релиза, распакует через `7z` и разложит нужные `.dll` файлы по папкам.

## ⚠️ РУЧНАЯ УСТАНОВКА (Windows)
Если вы находитесь на Windows, скрипт авто-скачивания не сработает (так как требует bash и 7z). Gradle выдаст вам ошибку с просьбой скачать файлы вручную.

**Как установить вручную:**
1. Скачать архив **`mpv-dev-x86_64-<версия>.7z`** со страницы релизов:
   - [zhongfly/mpv-winbuild Releases](https://github.com/zhongfly/mpv-winbuild/releases)
   - или [shinchiro/mpv-winbuild-cmake Releases](https://github.com/shinchiro/mpv-winbuild-cmake/releases)
2. Распаковать `libmpv-2.dll` из архива.
3. Переименовать / скопировать файл в текущую директорию под именами:
   - `mpv-2.dll`
   - `libmpv-2.dll`
4. Продублировать оба файла в папку `desktopApp/src/jvmMain/resources/win32-x86-64/`.

*(Примечание: Файлы .dll игнорируются в Git, так как их размер превышает 100 МБ).*
